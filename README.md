# Olion Art — инструкторский курс

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `olion-instructor`.
2. Распакуйте архив. Загрузите содержимое папки так, чтобы `index.html` был в корне репозитория.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch, затем main и / (root). Нажмите Save.
5. После публикации GitHub покажет адрес сайта.

Сайт поддерживает адрес вида https://USERNAME.github.io/olion-instructor/ и собственный домен.

## Редактирование

Тексты, пакеты и программа находятся в app.js; оформление — в style.css. Фотографии — рядом с index.html.
